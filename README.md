# SAT Prep Platform

A comprehensive SAT preparation website with practice tests for Math, Verbal, and Writing sections.

## Features
- **Three Practice Modes**: Math, Verbal, and Writing practice tests
- **Built-in Calculator**: DOS-style calculator for math problems
- **User Authentication**: Google Sign-In with data persistence
- **Timed Practice**: 10-minute practice sessions
- **Progress Tracking**: Save and resume practice sessions
- **Responsive Design**: Works on desktop and mobile devices
